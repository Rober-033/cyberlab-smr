Módulo 1: Fundamentos de HTML

HTML es el lenguaje base que se utiliza para estructurar el contenido de las páginas web mediante el uso de etiquetas y elementos semánticos.

1. Estructura Básica

Toda página web parte de una estructura estándar. En VS Code, puedes autogenerarla escribiendo ! y pulsando Enter.

Código Fuente

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi Web</title>
  </head>
  <body>
    <h1>Hola Mundo</h1>
  </body>
</html>

Hola Mundo

2. Títulos y Párrafos

Disponemos de encabezados (desde <h1> hasta <h6>) y párrafos de texto (<p>).

Código Fuente

<h2>Sección Principal</h2>
<p>Texto explicativo dentro de un párrafo.</p>

3. Listas (Ordenadas y No Ordenadas)

Se emplean para agrupar elementos en forma de viñetas (<ul>) o de forma numérica (<ol>) utilizando siempre ítems <li>.

Código Fuente

<ul>
  <li>Elemento con viñeta 1</li>
  <li>Elemento con viñeta 2</li>
</ul>

Vista Previa

  • Elemento con viñeta 1
  • Elemento con viñeta 2

4. Contenedores (div y span)

El elemento <div> actúa como un contenedor en bloque para agrupar secciones, mientras que <span> se usa en línea para fragmentos específicos de texto.

Código Fuente

<div style="padding: 10px; background: #1e293b;">
  Contenedor <span style="color: #34d399;">en línea</span>
</div>
