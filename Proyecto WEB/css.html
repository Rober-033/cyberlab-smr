Módulo 2: Introducción a CSS

CSS se encarga de dar diseño, color y distribución visual a nuestra página web. Las reglas se aplican mediante selectores vinculados a una hoja de estilos externa (style.css).

1. Selectores (ID vs Clases)

Los identificadores (#id) se usan para elementos únicos, mientras que las clases (.class) permiten reutilizar estilos en varios elementos.

Código Fuente (CSS)

/* Selector por ID */
#titulo-principal {
  color: red;
}

/* Selector por Clase */
.texto-destacado {
  color: blue;
}

2. Propiedades de Fondo (Background)

Permiten controlar colores, imágenes de fondo, repetición, tamaño (cover) y posición de forma avanzada.

Código Fuente (CSS)

.caja-fondo {
  background-color: #1e293b;
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

3. Estilos de Texto y Fuentes

Podemos modificar la familia de la fuente, el tamaño, el grosor (bold), el estilo (italic) y la alineación.

Código Fuente (CSS)

.estilo-texto {
  font-family: 'Segoe UI', sans-serif;
  font-size: 1rem;
  font-weight: bold;
  text-align: center;
}

4. Distribución (Flexbox)

Activando display: flex; podemos organizar los elementos en filas (row) o columnas (column) de manera flexible.

Código Fuente (CSS)

.contenedor-flex {
  display: flex;
  flex-direction: row;
  gap: 10px;
}
